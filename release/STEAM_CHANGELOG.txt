[h2]Version 0.16.0 - 3D chain[/h2]

[h3]New[/h3]
[list]
[*][b]3D chain between the vehicles:[/b] chains are now drawn as a real 3D model - link by link from hitch to hitch, sagging when slack, the links keep their size at any distance. Needs [i]3D ground items[/i] in the game options; otherwise the picture is used as before. Tow bars stay a picture.
[*][b]New look for the Heavy Chain with Hook:[/b] a coiled chain with two red hooks on the ground and in the hands, and a new inventory icon.
[/list]

[h3]Fixed[/h3]
[list]
[*]Vehicles from other mods without hitches of their own (for example the semi-trailers of the W900 mod): a vehicle coupled behind them was pulled upwards. Their hitches are now at wheel-hub height.
[/list]

[h3]Changed[/h3]
[list]
[*]The Java part was rebuilt (0.16.0). ZombieBuddy asks once more for approval - click [b]Yes[/b].
[/list]

[h2]Version 0.14.0 - New name "Multi-Vehicle Towing", options page in its own mod "DO Utilities"[/h2]

[h3]New[/h3]
[list]
[*][b]Restart hint:[/b] if you switch the mod on in the mod list while the game is running, ZombieBuddy loads the Java part, but it only works after a restart. [*]Only Lua changed: the Java part is untouched, ZombieBuddy does not ask for approval again.
[/list]

[list]

[h2]Version 0.12.5[/h2]

[b]ZombieBuddy is now optional![/b]
Without ZombieBuddy the mod runs in a [b]basic mode[/b]: the game's normal towing of two vehicles, plus cargo weight, extra fuel use, noise and the train display. Road trains of 3 or more vehicles and most other features still need ZombieBuddy - it stays strongly recommended.

[h3]New[/h3]
[list]
[*][b]Warning page[/b] in the setup assistant when ZombieBuddy is not active: what does not work without it and how to fix it.
[*][b]Red options:[/b] when ZombieBuddy is missing, all options that need it are written in red in [i]Options > Road Train[/i] and in the setup assistant.
[*][b]Debug section[/b] at the bottom of the options, hidden until "Show debug options" is ticked. It contains "Show setup assistant on next start" (moved here from General), a preview of the warning page and a preview of the red options.
[/list]

[h3]Changed[/h3]
[list]
[*]ZombieBuddy is no longer a required mod. In basic mode the mod's own radial menu entries (chains from the 3rd vehicle, tow bar, hazard lights) are hidden.
[*]The message on game start without ZombieBuddy now says "basic mode".
[*]The Java part was rebuilt for the new version number only. ZombieBuddy asks once more for approval - click [b]Yes[/b].
[/list]
